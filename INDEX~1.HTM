Cómo suscribirse

Google Calendar: Otros calendarios → + → Desde una URL → pegá el enlace.
Outlook (web): Agregar calendario → Suscribirse desde la web → pegá el enlace.
Apple: Archivo → Nueva suscripción de calendario → pegá el enlace.

Las fechas con ~ son estimadas (patrón oficial) hasta que el organismo confirma su cronograma. Se actualiza automáticamente el día 1 de cada mes.
